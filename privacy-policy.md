# Privacy Policy – AI Context Saver

Last updated: June 2026

## Introduction

AI Context Saver is a Chrome extension designed to help users save, summarize, organize, and continue AI conversations across platforms such as ChatGPT, Claude, Gemini, Copilot, and Perplexity.

Your privacy is important to us. This Privacy Policy explains what information the extension accesses, how it is used, and how your data is protected.

---

# Information We Access

AI Context Saver may access the following information only when the user actively uses the extension:

* Website content from supported AI platforms
* Conversation text visible on AI chat pages
* User interaction required for extraction features such as scrolling and clicking
* Extension settings and locally stored summaries

The extension does NOT collect:

* Passwords
* Authentication credentials
* Payment information
* Personal identity documents
* Health information
* GPS location
* Browsing history outside supported AI platforms

---

# How Data Is Used

The extension uses accessed data only for its core functionality:

* Extracting AI conversations
* Generating summaries
* Compressing long chats into reusable context
* Allowing users to save and continue conversations later
* Improving productivity workflows

Data is never used for advertising, profiling, or tracking.

---

# AI API Usage

If users choose to enable AI-powered summarization, selected conversation content may be sent securely to the user’s chosen AI provider, such as:

* Mistral AI
* Claude API
* Other user-configured AI services

API keys are stored locally in the browser and are never shared with the developer.

Users are fully responsible for the external AI services they choose to connect.

---

# Local Storage

Most data is stored locally on the user’s device using Chrome extension storage.

Saved conversations, summaries, settings, and preferences remain under the user’s control.

---

# Data Sharing

AI Context Saver does NOT:

* Sell user data
* Rent user data
* Transfer user data to advertisers
* Share user data with third parties for marketing purposes

Data is only processed for the extension’s stated functionality.

---

# Security

We take reasonable measures to protect user information and minimize unnecessary data access.

The extension only activates on supported AI platforms and only when the user uses the extension features.

---

# User Control

Users can:

* Delete saved conversations at any time
* Remove stored API keys
* Disable the extension
* Uninstall the extension completely

Removing the extension deletes locally stored extension data from the browser.

---

# Changes to This Policy

This Privacy Policy may be updated in the future to reflect feature or policy changes.

Users are encouraged to review the latest version periodically.
